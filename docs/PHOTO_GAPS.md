# Plants still missing a catalogued photo

As checked on 7 November 2026: **21 of 1,386 species** have no preselected photo in Chloris. The live GBIF lookup may still find one when a species page opens. All 12 featured and all four at-risk species have catalogued photos.

For a candidate, search [Wikimedia Commons](https://commons.wikimedia.org/wiki/Special:MediaSearch?type=image) or [iNaturalist](https://www.inaturalist.org/observations). Send the exact species name, the image or file page, photographer, and image-level licence. Chloris accepts CC0 or CC BY; the only CC BY-NC exception is *Galanthus ikariae*. Do not use herbarium sheets or a different species. Photos you own can be added using the README instructions.
